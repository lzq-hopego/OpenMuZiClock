## 新旧版本说明
带 **old**的为旧版本(支持jwt获取和风天气)，旧版本指的是旧的接线图，可参考dudu时钟的屏幕接线方案，蜂鸣器io0、光敏电阻io1，ds18b20为io6
结尾带日期的为新版本(支持jwt获取和风天气以及一些小bug的修复)，旧版本只会修复重要功能，新版本为主要更新版本，新版本io如下表所示:
| 引脚编号 | 功能用途                | 所属模块/说明                     | 备注                                  |
|----------|-------------------------|-----------------------------------|---------------------------------------|
| 0        | BUZZER（蜂鸣器）        | 音频输出                          | 引脚0为Arduino硬件串口RX，使用时注意和串口冲突 |
| 1        | ldrPin（左侧光敏电阻）  | 模拟/数字输入（光敏电阻检测）     | 引脚1为Arduino硬件串口TX，使用时注意和串口冲突 |
| 2        | TFT_RST（TFT屏幕复位）  | TFT液晶屏控制                     | 可接开发板RST引脚（若复用需注意复位逻辑） |
| 3        | TFT_SCLK（TFT屏幕时钟） | TFT液晶屏SPI通信                  | SPI总线SCLK引脚，需和SPI时序匹配       |
| 5        | ONE_WIRE_BUS            | 单总线（如DS18B20温度传感器）     | 单总线通信引脚，需上拉电阻（4.7KΩ）    |
| 6        | TFT_CS（TFT屏幕片选）   | TFT液晶屏SPI片选                  | SPI片选引脚，低电平有效                |
| 7        | TFT_MOSI/SDA（TFT屏幕数据） | TFT液晶屏SPI通信                  | SPI总线MOSI引脚（仅输出）              |
| 8        | BUTTON（按钮）          | 按键输入（需上拉/下拉电阻）       | 建议设置内部上拉电阻，避免电平漂移     |
| 10       | TFT_DC（TFT屏幕数据/命令） | TFT液晶屏控制                   | 区分SPI传输的是数据还是命令            |
